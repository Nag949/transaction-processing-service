## Running the Application

### Method 1: Using Maven Exec Plugin
```bash
mvn exec:java -Dexec.mainClass="com.transaction.TransactionProcessingApplication"
```

### Method 2: Using Java JAR
```bash
# First package the JAR
mvn clean package

# Run the JAR
java -jar target/transaction-processing-service-1.0.0.jar
```

### Method 3: Direct Java Execution (After Compilation)
```bash
# Compile first
mvn compile

# Run directly
java -cp target/classes;target/dependency/* com.transaction.TransactionProcessingApplication
```

## Test Coverage

The test suite includes 12 test cases covering:

1. **testDuplicateRequestDetection** - Tests requestId-based deduplication
2. **testDuplicateTransactionDetection** - Tests transactionId-based deduplication
3. **testOutOfOrderProcessing** - Tests sequence-based out-of-order handling
4. **testInOrderProcessing** - Tests normal sequential processing
5. **testInvalidTransactionValidation** - Tests validation failures (negative amounts)
6. **testNullTransactionValidation** - Tests null request handling
7. **testRetryScenario** - Tests transient failure and retry logic
8. **testInsufficientFundsDebit** - Tests business logic failures
9. **testCreditAndDebit** - Tests basic credit/debit operations
10. **testMultipleAccounts** - Tests transactions across multiple accounts
11. **testServiceReset** - Tests state reset functionality
12. **testAssessmentScenario** - Tests the full assessment scenario

## Troubleshooting

### Issue: Maven not found
**Solution**: Ensure Maven is installed and added to PATH
```bash
# Verify Maven installation
mvn -version

# If not found, add Maven to system PATH
# Windows: Add MAVEN_HOME/bin to PATH environment variable
```

### Issue: Java version mismatch
**Solution**: Ensure Java 17 is installed and configured
```bash
# Verify Java version
java -version

# Set JAVA_HOME environment variable to Java 17 installation
# Windows: Set JAVA_HOME=C:\Program Files\Java\jdk-17
```

### Issue: Build failures
**Solution**: Clean and rebuild
```bash
mvn clean install -U
```
The `-U` flag forces update of snapshots and releases

### Issue: Test failures
**Solution**: Check test output for specific failure reasons
```bash
mvn test -Dtest=TransactionProcessingServiceTest
```
Review the error messages in the console output

### Issue: Port conflicts
**Solution**: This application does not use any external ports, so port conflicts should not occur

### Issue: Logging not visible
**Solution**: Check logback.xml configuration
```bash
# View logging configuration
type src\main\resources\logback.xml

# Ensure log level is set to INFO or DEBUG
```

## Customization

### Change Retry Configuration
Edit `src/main/java/com/transaction/processor/TransactionProcessor.java`:
```java
private static final int MAX_RETRY_COUNT = 2;  // Change this value
```

### Change Simulated Failure Transaction
Edit `src/main/java/com/transaction/processor/TransactionProcessor.java`:
```java
private static final String SIMULATED_FAILURE_TXN_ID = "TXN-2005";  // Change this ID
```

### Change Logging Level
Edit `src/main/resources/logback.xml`:
```xml
<logger name="com.transaction" level="DEBUG"/>  <!-- Change to DEBUG for detailed logs -->
```

### Modify Test Data
Edit `src/main/java/com/transaction/TransactionProcessingApplication.java`:
```java
private static List<TransactionRequest> createTestData() {
    // Add or modify test transactions here
}
```
