# Sample Input and Output

## Sample Input Data

The service processes a batch of 6 transaction requests that demonstrate the key features:

### Transaction Request 1 (Out-of-Order Arrival)
```json
{
  "transactionId": "TXN-2002",
  "accountId": "ACC-201",
  "transactionType": "DEBIT",
  "amount": 40.0,
  "currency": "USD",
  "sequenceNumber": 2,
  "requestId": "REQ-2",
  "eventTime": "2024-01-01T10:00:00Z"
}
```
**Expected Behavior**: Arrives first but sequence is 2 (should be PENDING until sequence 1 arrives)

### Transaction Request 2 (In-Order Processing)
```json
{
  "transactionId": "TXN-2001",
  "accountId": "ACC-201",
  "transactionType": "CREDIT",
  "amount": 100.0,
  "currency": "USD",
  "sequenceNumber": 1,
  "requestId": "REQ-1",
  "eventTime": "2024-01-01T10:00:01Z"
}
```
**Expected Behavior**: Arrives second but sequence is 1 (should be PROCESSED immediately)

### Transaction Request 3 (Duplicate Transaction)
```json
{
  "transactionId": "TXN-2002",
  "accountId": "ACC-201",
  "transactionType": "DEBIT",
  "amount": 40.0,
  "currency": "USD",
  "sequenceNumber": 2,
  "requestId": "REQ-2-DUP",
  "eventTime": "2024-01-01T10:00:02Z"
}
```
**Expected Behavior**: Same transactionId as request 1, different requestId (should be DUPLICATE)

### Transaction Request 4 (Sequential Processing)
```json
{
  "transactionId": "TXN-2003",
  "accountId": "ACC-201",
  "transactionType": "CREDIT",
  "amount": 25.0,
  "currency": "USD",
  "sequenceNumber": 3,
  "requestId": "REQ-3",
  "eventTime": "2024-01-01T10:00:03Z"
}
```
**Expected Behavior**: Sequence 3, should be PROCESSED after sequence 2 is handled

### Transaction Request 5 (Validation Failure)
```json
{
  "transactionId": "TXN-2004",
  "accountId": "ACC-202",
  "transactionType": "DEBIT",
  "amount": -10.0,
  "currency": "USD",
  "sequenceNumber": 4,
  "requestId": "REQ-4",
  "eventTime": "2024-01-01T10:00:04Z"
}
```
**Expected Behavior**: Negative amount (should fail validation with FAILED status)

### Transaction Request 6 (Retry Scenario)
```json
{
  "transactionId": "TXN-2005",
  "accountId": "ACC-203",
  "transactionType": "CREDIT",
  "amount": 500.0,
  "currency": "USD",
  "sequenceNumber": 1,
  "requestId": "REQ-5",
  "eventTime": "2024-01-01T10:00:05Z"
}
```
**Expected Behavior**: Simulates transient failure on first attempt, succeeds after retry

## Transaction Processing Flow

### Step-by-Step Execution

1. **TXN-2002 (sequence 2)** arrives first
   - Status: PENDING (waiting for sequence 1)
   - Account balance: unchanged

2. **TXN-2001 (sequence 1)** arrives second
   - Status: PROCESSED
   - Account balance: ACC-201 = 100.0
   - Triggers processing of pending TXN-2002

3. **TXN-2002 (duplicate with REQ-2-DUP)** arrives third
   - Status: DUPLICATE (transactionId already processed)
   - Account balance: unchanged

4. **TXN-2003 (sequence 3)** arrives fourth
   - Status: PROCESSED
   - Account balance: ACC-201 = 125.0

5. **TXN-2004 (negative amount)** arrives fifth
   - Status: FAILED (validation error)
   - Account balance: unchanged

6. **TXN-2005 (retry scenario)** arrives sixth
   - First attempt: Transient failure
   - Retry attempt: Success
   - Status: PROCESSED
   - Retry count: 1
   - Account balance: ACC-203 = 500.0
